# Autonomous Mobile Robotics

ROS 2 development and lab work focused on autonomous mobile robots using the TurtleBot4 platform.

## Labs

The course consists of four TurtleBot4 labs covering the core concepts of autonomous mobile robotics:

* **Lab 1 — Sensors & Robot Interface**

  * TurtleBot4 setup
  * Sensor data read/write
  * Robot hardware and ROS 2 interfaces

* **Lab 2 — Closed-Loop Control**

  * Robot control
  * Feedback and closed-loop controllers

* **Lab 3 — Estimation & Localization**

  * State estimation
  * Robot localization

* **Lab 4 — Planning & Navigation**

  * Path planning
  * Autonomous navigation

## Tech Stack

* ROS 2 Humble
* TurtleBot4
* Ubuntu 22.04
* Docker
* C++ / Python

> This repository contains my own development environment, implementations, and notes. Additional work and documentation will be added as the labs are completed.
